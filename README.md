# Projeto Calculadora – Java

## Sobre o Projeto

A Calculadora é uma aplicação desenvolvida em Java com a finalidade de executar cálculos matemáticos básicos por meio de dois números inteiros e um operador informado pelo usuário.

O projeto foi desenvolvido com uma estrutura simples, utilizando métodos específicos para realizar os cálculos, formatar os resultados e identificar possíveis erros durante a execução.

## Finalidade da Atividade

Esta atividade tem como finalidade colocar em prática os conhecimentos adquiridos sobre desenvolvimento em Java, organização de classes e métodos, refatoração e testes de software.

Durante o desenvolvimento, também foram utilizados recursos de documentação automática e controle de versão.

## Ferramentas e Tecnologias

As seguintes tecnologias foram utilizadas:

1. **Java:** responsável pela implementação da calculadora.
2. **JUnit 5:** utilizado na criação e execução dos testes automatizados.
3. **JavaDoc:** responsável pela geração da documentação técnica em formato HTML.
4. **GitHub:** utilizado para hospedar o projeto e disponibilizar seus arquivos.

## Funcionamento da Aplicação

A calculadora recebe três informações: dois números inteiros e um operador matemático. Com base no operador recebido, o programa executa o cálculo correspondente.

### Operações implementadas

**Adição (+)**

Realiza a soma entre os dois valores informados.

**Subtração (-)**

Calcula a diferença entre o primeiro e o segundo número.

**Multiplicação (*)**

Multiplica os valores recebidos como entrada.

**Divisão (/)**

Realiza a divisão inteira entre os números. Caso o segundo valor seja zero, o programa retorna uma mensagem informando que a operação não pode ser realizada.

### Tratamento de erros

Além das operações matemáticas, foram implementadas verificações para evitar situações inválidas:

- Identificação de operadores não suportados.
- Verificação de operador nulo.
- Impedimento de divisão por zero.

## Validação por Testes

Para verificar se a aplicação está funcionando corretamente, foram criados testes unitários utilizando JUnit 5.

Os testes verificam individualmente cada operação matemática, além das situações de erro previstas na implementação.
